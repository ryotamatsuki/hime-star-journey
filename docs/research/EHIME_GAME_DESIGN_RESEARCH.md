# EHIME GAME DESIGN RESEARCH

## 0. 調査目的

本書は愛媛県20市町を「観光地20個の背景素材」へ還元せず、地形、自然、水系、歴史、文化、産業、暮らしをRPGの移動・探索・戦闘・星の異変へ変換するための調査ノートである。

事実確認は愛媛県、各市町、文化財・地域史資料を優先し、RPG化アイデアは事実記述と分ける。伝承・祭礼・信仰そのものを敵として倒す構図は避け、敵候補は原則「濁りが土地の形を借りた影」とする。

## 1. 県全体の構造

### 1.1 20市町と3地域

愛媛県は11市9町の20市町で、東予・中予・南予の3地域に分かれる。県の国土利用計画では、高縄山脈以東を東予、石鎚山脈以南を南予、その間を中予とする地域性が整理されている。

- 東予: 今治市、新居浜市、西条市、四国中央市、上島町。
- 中予: 松山市、伊予市、東温市、久万高原町、松前町、砥部町。
- 南予: 宇和島市、八幡浜市、大洲市、西予市、内子町、伊方町、松野町、鬼北町、愛南町。

ゲームでは行政区画線を直接ダンジョン境界にせず、山・川・海・産業のつながりをAdventure Area境界に使う。

### 1.2 地形と水

県土は東西に長く、石鎚山（1,982m）を主軸とした山岳地形を持つ。東予には道前平野、中予には道後平野、南予には大洲・宇和・三間などの盆地が点在する。瀬戸内海・宇和海には多数の島があり、山地から海までの距離が短い地域が多い。

県河川課は、瀬戸内側は温暖少雨、宇和海側・四国山地はより降水量が多く、河川は短く急で、水資源確保に苦労してきた歴史があると整理している。

### 1.3 ゲーム化する県全体の軸

P11では愛媛を「名所の集合」ではなく、次の5本の自然・生活ネットワークとして読む。

1. **湯・地下水・川**: 道後の湯→重信川周辺→西条のうちぬき→肱川→宇和海。
2. **風・島・港**: しまなみ・来島海峡→上島→佐田岬→宇和海。
3. **山・古道・森**: 石鎚山系→東温渓谷→久万高原→南予の森林・滑床。
4. **ものづくりの流れ**: 砥部焼、別子銅山、紙、造船、タオル、真珠・養殖。
5. **記憶を残す文化**: 城下町、町並み、遍路、祭礼、神楽、鹿踊り、牛鬼、地域の伝承。

これが、湯・風・山・灯り・海の5能力とAdventure Area構成の根拠である。

## 2. 歴史・文化・自然・産業の主要素材

### 道後温泉 / 白鷺

松山市公式は道後温泉を約3,000年の歴史を持つとされる温泉として紹介し、傷ついた白鷺が湯で癒えた伝説を掲載している。白鷺は道後温泉本館にも象徴として用いられている。

**ゲーム転用**: シロを「白鷺の伝説をコピーしたマスコット」ではなく、土地を導き、傷んだものを元へ戻すという白鷺モチーフの意味へ接続する。既存設定と非常に相性が良い。

### 松山城

松山市公式では、松山城は江戸時代までに建造された天守が残る「現存12天守」の一つとされる。

**ゲーム転用**: 石垣、登城道、天守を一本道の観光案内にせず、「守る力が固まりすぎる」カゲマサの物語へ結びつける。既存MVPを維持。

### 石鎚信仰

石鎚山は西日本最高峰で、古くから山岳信仰・修験の場として知られる。成就社や山頂社等の信仰空間、登拝の歴史がある。

**ゲーム転用**: 信仰対象を敵や単純な魔法装置にしない。霧の中で古道・水音・白い印を探す「道を見つける体験」にし、鎖場等の危険な登山行為を子ども向けアクションへ軽率に模倣しない。

### 四国遍路

四国八十八ヶ所霊場は四県にまたがる巡礼文化で、愛媛にも多数の札所がある。

**ゲーム転用**: 札所を全部collectibleにしない。道・休憩・人が旅人を支える文化として、遍路道沿いの小さな「お接待」的支援や道標の発想をNPC・checkpointに生かす。

### 砥部焼

砥部町公式によれば砥部焼は約250年の歴史を持ち、地元の陶石を原料としてきた。町内には多くの窯元があり、白磁と藍の意匠等が特徴。

**ゲーム転用**: 「皿を集める」ではなく、陶石→土→形→窯という工程を、水と熱を整える短い環境パズルに変換する。

### 内子町並み / 木蝋・和紙

内子は八日市護国地区等の歴史的町並み、木蝋・和紙などの生業、小田川・森林地域を持つ。

**ゲーム転用**: 古い家を眺めるのではなく「灯りが消えると、人の動きの記憶も見えなくなる」異変にする。灯りを戻すたび、昔の作業・芝居・行き交う人の輪郭が短く戻る。

### 大洲城 / 肱川 / 臥龍山荘

大洲は肱川が大きく湾曲する城下町で、大洲城、臥龍山荘等の歴史景観を持つ。臥龍山荘は肱川の景観を取り込む庭園として評価される。

**ゲーム転用**: 城だけをゴールにせず、内子の小田川側から肱川へ光が流れる「川が町の記憶をつなぐ」Areaにする。

### 宇和島城 / 伊達文化 / 牛鬼

宇和島は現存天守を持つ宇和島城、宇和島伊達家に由来する城下町文化、牛鬼等の祭礼文化を持つ。

**ゲーム転用**: 牛鬼そのものを倒す敵にしない。地域の人々が濁りに対抗する祭礼の守り／大きな動きとして扱い、敵は「牛鬼の形を借りた影」と明示的に区別する。

### 村上海賊

瀬戸内の村上海賊は島・海峡を基盤とし、海上交通・警固・航路に関わった歴史を持つ。

**ゲーム転用**: 「海賊＝略奪者」のステレオタイプを避け、潮と風を読み、島の間の道を知る知恵としてA2へ使う。

### 別子銅山

別子銅山は新居浜の山から臨海部へ至る長い産業史を持つ。採鉱だけでなく運搬・精錬・港・都市形成まで「山から海へ」の流れが重要。

**ゲーム転用**: 鉱山内部だけのダンジョンにせず、山側機構→運搬→港→四国中央の水・紙へつなぐ。

### 新居浜太鼓祭り / 西条祭り

東予の大規模祭礼は、地域の共同体、豪華な太鼓台・だんじり等の動きが強い視覚資産。

**ゲーム転用**: 戦闘用モンスター化せず、Area復旧後に町の大きな動き・音が戻るcelebrationとして使う。協力して重いものを動かす演出へも転用可能。

### 鹿踊り・神楽

南予には鹿踊りや神楽等の民俗芸能が伝わる地域がある。

**ゲーム転用**: 「鹿＝敵」ではなく、音・踊りが森の道を示す守りの記憶にする。敵化が必要な場合は「鹿の影」「濁りが借りた姿」と区別する。

## 3. 自然素材のゲーム変換

| 自然 | 現地性 | RPGへの変換 |
|---|---|---|
| 石鎚山 | 高峰・信仰・山道 | 黒霧、水音、星印の古道を読む探索 |
| 面河渓 | 石鎚山系の渓谷 | 水と岩の音、冷えた星水脈 |
| 滑床渓谷 | 花崗岩の滑らかな河床と森 | 森の水が海へ届くA7上流route |
| 四国カルスト | 高地の開放景観 | 遠景landmarkと風向きで道を選ぶ |
| しまなみ海道 | 島と橋 | 一本道の橋walkではなく島route選択 |
| 来島海峡 | 強い潮流 | 風・潮が渡れる道を変える |
| 瀬戸内の島々 | 多島海 | 小SubareaをつなぐAdventure Area構造そのもの |
| 佐田岬 | 細長い半島、二つの海 | 北／南で風・潮状態が変わる |
| 宇和海 | リアス海岸、養殖・真珠 | 森の水と海の暮らしを連動させる |
| 肱川 | 大洲を流れる河川 | 内子→大洲の灯り・記憶の流路 |

## 4. 産業素材のゲーム変換

- **みかん・柑橘**: 拾うだけのcollectibleにしない。段々畑をlandmarkにし、みかん星の色・光・家庭の記憶へ接続。
- **真珠・養殖**: 「宝石を集める」より、潮が正常に戻ると海中の星印と暮らしが戻る表現。
- **今治タオル**: item名称の羅列より、水・織る・風で乾く工程を短いenvironmental storytellingへ。
- **紙**: 水と風を使うA4パズル、書道の筆跡を「流れ」として可視化。
- **造船**: 巨大船を運転させず、港のscale感・島間移動の拠点・風を受ける構造物へ。
- **鉱山**: 別子の山→港という縦の移動と機構復旧。
- **窯業**: 砥部焼の陶石・水・熱をA1に統合。
- **林業**: 久万高原・内子・松野等で「森が道と水を育てる」環境rule。
- **農業**: 松前の麦、南予柑橘等を生活景観・NPCeventへ。
- **漁業**: 宇和海の海面だけでなく、潮・港・山からの水との関係へ。

## 5. 20市町ゲームデザイン調査

以下の「星候補」は20個の土地の星のテーマ名候補であり、すべてがglobal field abilityを与えるわけではない。

### 5.1 松山市

- **景観・自然**: 道後平野、瀬戸内海、城山、道後温泉。
- **歴史・文化**: 道後温泉、白鷺伝説、松山城、俳句文化、遍路。
- **産業・暮らし**: 県都の都市機能、観光、商業。
- **RPG化**: 既存MVPをPrologueとして維持。温泉の異変→城の「守る力」の濁りへつなぐ。
- **星候補**: 湯の星、城の星。
- **ギミック**: 湯けむり、灯り、石垣、井戸。
- **敵候補**: 既存の湯どろぼう鬼、あお提灯、影足軽等。
- **カード候補**: 道後の湯しずく、城山のまもり（既存）。
- **Area**: A0。

### 5.2 伊予市

- **景観・自然**: 瀬戸内海沿岸の双海、平野から中山方面の山地へ連続する地形。
- **歴史・文化**: 郡中等の町の歴史、海沿いの暮らし。
- **産業**: 農業、柑橘、海側の産業。
- **RPG化**: 中予平野側と海側をつなぐ「水が海へ届く道」の最初の分岐。
- **星候補**: 海風の星／夕波の星。
- **ギミック**: 海風で揺れる目印、浅い水路、坂道。
- **敵候補**: しおかぜ影、みずどめ小鬼。
- **カード候補**: `夕波ガード`（1回だけ次の攻撃を軽減）。
- **Area**: A1。

### 5.3 松前町

- **景観・自然**: 松山平野の平坦な生活圏、水路と農地。
- **歴史・文化**: 義農作兵衛の伝承、地域の農の歴史。
- **産業**: はだか麦等の農業、商工業。
- **RPG化**: 広い平地を「何もない空間」にせず、麦畑と水路の短い迷路・風の見える道にする。
- **星候補**: 麦の星。
- **ギミック**: 水門、麦の揺れが示す近道。
- **敵候補**: むぎわらコロリ、みずせき影。
- **カード候補**: `むぎのひとやすみ`（小回復＋次turn MP軽減）。
- **Area**: A1。

### 5.4 砥部町

- **景観・自然**: 砥部川、北部盆地から南部山間へ上がる地形。
- **歴史・文化**: 約250年の砥部焼、陶石、窯元。
- **産業**: 窯業、農林業。
- **RPG化**: 陶石→水→形→熱という工程を、A0で得た「あたため」を初めて本編で再利用する仕掛けへ。
- **星候補**: 器の星。
- **ギミック**: 冷えた窯、器の形を合わせる水路、白い陶石のlandmark。
- **敵候補**: ひびわれこぞう、かまけむり影。
- **カード候補**: `しろじのうつわ`（受けた状態変化を1回無効）。
- **Area**: A1。

### 5.5 東温市

- **景観・自然**: 白猪の滝、滑川渓谷、重信川上流域。
- **歴史・文化**: 渓谷・滝に関わる地域史、漱石らの訪問記録もある。
- **産業**: 農業、都市近郊産業。
- **RPG化**: 水音は聞こえるが霧で道が見えないA3の「音で探す」Subarea。
- **星候補**: 滝音の星。
- **ギミック**: 甌穴・岩層を視覚手掛かりにした安全な道探し。
- **敵候補**: きりかくし、こだま影。
- **カード候補**: `しらいのしずく`（回復＋霧弱点表示）。
- **Area**: A3。

### 5.6 久万高原町

- **景観・自然**: 石鎚山系、面河渓、四国カルスト、森林・高地。
- **歴史・文化**: 山村、遍路道・山岳文化。
- **産業**: 林業・農業。
- **RPG化**: 遠景がよく見える高原と、視界を奪う霧の古道を対比。石鎚信仰を敵化せず「山を畏れ、道を読む」感覚へ。
- **星候補**: 高原の星／山の星。
- **ギミック**: 風で一時的に霧が晴れ、星印の安全な古道が見える。
- **敵候補**: みちまどわし影、くもり岩。
- **カード候補**: `高原の風`（次turnの風card補助）。
- **Area**: A3。

### 5.7 今治市

- **景観・自然**: しまなみ海道、来島海峡、多島海、港。
- **歴史・文化**: 村上海賊、島の海上交通。
- **産業**: 造船、海運、タオル、農漁業。
- **RPG化**: 橋背景ではなく「風が止まって島間移動できない」。橋route／小舟routeの二択。
- **星候補**: 風の星。
- **ギミック**: 帆、風車、旗、潮、見張り台。
- **敵候補**: かぜぬすみ、くろほガモメ。
- **カード候補**: `しまかぜ`（風状態turnで追加効果）。
- **Area**: A2 / P12。

### 5.8 上島町

- **景観・自然**: 弓削・生名・岩城・魚島等を含む多数の島、穏やかな瀬戸内海。
- **歴史・文化**: 塩づくり等の歴史、島ごとの生活文化。
- **産業**: 農漁業、造船関連、柑橘等。
- **RPG化**: 島を「全部同じ小マップ」にせず、短い島道を選び、風の戻り方が島ごとに違う構造。
- **星候補**: 島むすびの星。
- **ギミック**: 島ごとの風向き、港の短いshortcut、潮待ち。
- **敵候補**: しおガニ影、いしぶねこぞう。
- **カード候補**: `島むすび`（2体戦で片方を守りつつもう片方へ攻撃補助）。
- **Area**: A2 / P12。

### 5.9 西条市

- **景観・自然**: 石鎚山、道前平野、豊かな地下水「うちぬき」。
- **歴史・文化**: 石鎚信仰、西条祭り等。
- **産業**: 農業、工業、水を利用した産業。
- **RPG化**: 山から見えない地下へ続く水脈を「音と湧水地点」で追うA3 Hub。
- **星候補**: 水脈の星。
- **ギミック**: 地上の水印をつなぐと地下の星路が浮かぶ。
- **敵候補**: みずかくし石、しろがねカラス影。
- **カード候補**: `うちぬき`（HP小回復＋MP1回復）。
- **Area**: A3。

### 5.10 新居浜市

- **景観・自然**: 別子山地から臨海部へ下る大きな高低差。
- **歴史・文化**: 別子銅山、新居浜太鼓祭り。
- **産業**: 鉱山を起点とした工業・港湾。
- **RPG化**: 「坑道1個」ではなく、山の資源が運搬路・港へ移る縦の回廊。止まった機構を既得能力で一つずつ再接続。
- **星候補**: 銅の星／運ぶ星。
- **ギミック**: 搬送路、山道、温度で固まった機構。
- **敵候補**: くろがねムシ、からまりワイヤー影。
- **カード候補**: `別子のひびき`（まもり解除に強い）。
- **Area**: A4。

### 5.11 四国中央市

- **景観・自然**: 瀬戸内沿岸と山地、水資源を利用する産業都市。
- **歴史・文化**: 紙・和紙、水引、書道に関連する文化。
- **産業**: 製紙・紙加工が大きな特色。
- **RPG化**: 紙製品名を並べず、水→紙→風→文字という「流れ」を遊ぶ。黒い力で紙が全部同じ模様になる異変。
- **星候補**: 紙の星。
- **ギミック**: 紙がめくれる方向、筆跡を流れとしてなぞる、風で乾かす。
- **敵候補**: すみべた小僧、かみまき影。
- **カード候補**: `紙のつつみ`（1turn shield）。
- **Area**: A4。

### 5.12 内子町

- **景観・自然**: 山地・森林、小田川、歴史的町並み。
- **歴史・文化**: 木蝋、和紙、内子座、八日市護国の町並み。
- **産業**: 林業・農業、伝統産業。
- **RPG化**: 夜の町から灯りと「人が暮らした動き」の記憶が消える。灯りを戻すたびに短い過去の輪郭が重なる。
- **星候補**: 灯りの星。
- **ギミック**: 和紙の透過、木蝋灯、劇場の灯り順序。
- **敵候補**: わすれ紙、からっぽ提灯影。
- **カード候補**: `内子の灯`（敵の次行動を1つ見せる）。
- **Area**: A5。

### 5.13 大洲市

- **景観・自然**: 肱川、大洲盆地、城下町、臥龍淵。
- **歴史・文化**: 大洲城、臥龍山荘、城下町。

## 6. 20市町をAdventure Areaへ束ねる理由

### A1 伊予・松前・砥部

地理的に松山周辺から南・西へ続き、平野の水、海、砥部川、陶石・窯を「水を受け止める器」という一つの遊びへまとめられる。最初の本編Areaとして派手な新能力を増やさず、湯の星再利用と軽い分岐を教える。

### A2 今治・上島

多島海と海上交通という共通の空間ルールがあり、Wind abilityを最も自然に導入できる。島ごとに行政stageを分けるより、route choiceそのものが地域らしさになる。

### A3 西条・東温・久万高原

石鎚山系、水、渓谷、高地を「見えない水脈・霧・古道」で統合できる。山岳信仰を敵化せず、道を探す行為へ変換できる。

### A4 新居浜・四国中央

新居浜の山→港と、四国中央の水→紙を「資源が流れて形になる」産業回廊としてつなげる。新能力を増やさず東予で得た能力の複合応用にする。

### A5 内子・大洲

小田川・肱川、町並み、城下町、灯り・和紙・木蝋を「川を流れる記憶と灯り」で結べる。

### A6 八幡浜・伊方・西予

佐田岬の二つの海、港、高低差・地層という「境目」の体験を作れる。Sea ability導入に適する。

### A7 宇和島・松野・鬼北・愛南

森林・河川・宇和海を上流から海まで一つの生態・生活連鎖として扱える。4市町と多いが、個別観光stageを作るのではなく「森の水が海へ届く」二route構造にすることで南予編のclimaxになる。

## 7. 採用しない地域表現

- 市町名を出した直後に「名物3択クイズ」を置く。
- 実在祭礼・信仰・伝承を、その地域の悪いmonsterとして倒す。
- みかん、タオル、紙、真珠を大量collectibleにして数を埋める。
- 名所の写真背景＋説明文だけで「地域らしさ」を表現したことにする。
- 20市町を均等な尺にする。
- 行政境界を越えた瞬間だけBGM・敵skinが変わり、遊びは同じままにする。
- 実在の危険な登山・海上行動を、子どもが真似しうる形でリアルに操作再現する。

## 9. P12へ持ち込む地域調査上の検証課題

しまなみVertical Sliceでは、実装前に以下をさらに一次資料で詰める。

1. 今治・上島でゲーム上使う具体的な島routeと海峡の選定。
2. 村上海賊を「潮・航路・警固の知恵」として描く際の史実表現監修。
3. 来島海峡の潮流を子ども向け二状態ruleへ単純化する範囲。
4. 上島の塩・柑橘・造船関連をどこまでNPCeventへ入れるか。
5. 実在橋梁・航路を現実の距離そのままに再現せず、絵本的圧縮をどの程度行うか。

P11の調査は地域のゲームデザイン方向を決めるには十分だが、P12で実在する個別地点・島名をruntimeへ固定する前に、現地公式資料と文化財資料を再確認する。
